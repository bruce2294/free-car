### 1. 프로젝트 개요

**프리카:** 자동차 구독 이용권 쇼핑몰
**서비스 정의:** 사용자가 회원가입 후, 원하는 기간(일/주/월 단위) 동안 자동차를 "이용권" 형태로 구매하면, 지정한 시간·장소로 차량이 배송되고, 이용 기간에 맞춰 자동차 보험이 자동 가입되며, 만료일에 맞춰 차량이 회수되는 자동차 구독 커머스 플랫폼.

**메인 페이지 구성 (상단→하단 순):**
1. 헤더 (로그인/회원가입, 검색, 카테고리 GNB, 장바구니/찜, 마이페이지)
2. 메인 배너 (프로모션/신차/이벤트 롤링 배너)
3. 전기차 상품 items (카드형 리스트)
4. 스포츠카 상품 items
5. 럭셔리카 상품 items
6. SUV 상품 items
7. 미니밴 상품 items
8. 특별할인 이벤트 상품 items
9. 푸터 (회사정보, 약관, 고객센터, SNS)

**핵심 비즈니스 로직:**
- 회원은 이용 기간(예: 7일/1개월/3개월/6개월/12개월 등)을 선택해 차량 이용권을 구매
- 구매 시 사용자 정보(운전면허, 생년월일, 주소 등)를 입력받아 선택한 기간에 맞춰 **자동차 보험을 자동 가입** 처리 (보험사 연동 필요)
- 결제 완료 → **상품(차량) 준비** 프로세스 시작 → 사용자가 지정한 일시에 지정 장소로 **차량 탁송(배송)** → 이용 기간 만료일에 맞춰 **차량 회수**
- **환불 정책**: 보험 이용약관 및 환불 정책에 따라 위약금/일할 계산 등을 적용한 환불 처리
- **쿠폰 기능**: 정률/정액 할인 쿠폰 발급, 등록, 사용, 만료 관리

**시스템 구성 (3-Tier 시스템 분리):**
| 시스템 | 설명 |
|---|---|
| 서비스 시스템 (Front/API) | 일반 사용자가 이용하는 쇼핑몰 웹/앱 서비스 |
| 관리자 시스템 (Admin) | 상품/재고(차량)/주문/보험/쿠폰/정산/CS 관리 |
| 배치 시스템 (Batch) | 보험 가입 연동, 차량 배송·회수 스케줄링, 만료 처리, 쿠폰 만료, 정산 배치 등 |

**기술 스택 (필수 반영):**
- Frontend: **Vue.js** (Vue 3 + Vite, Pinia, Vue Router 가정)
- Backend: **Kotlin + Spring Boot** (서비스/관리자 API), **Spring Batch** (배치 시스템)
- 인프라/운영: **Docker, Kubernetes(k8s)**
- 메시징/이벤트: **Kafka** (주문-보험가입-배송-회수 간 비동기 이벤트 처리)
- (필요 시 가정 추가 가능: RDB는 MySQL/PostgreSQL, 캐시는 Redis, 검색은 Elasticsearch, CI/CD는 Jenkins/GitHub Actions + ArgoCD 등 — 문서 내에서 가정임을 명시하고 진행)

### 2. 요청 문서 목록 및 필수 포함 항목

아래 **6대 문서군**을 순서대로, 각 항목을 세부 목차 수준까지 구체적으로 작성하십시오. 표, 리스트, ERD/다이어그램은 텍스트 기반(마크다운 표, mermaid 다이어그램 코드, ASCII 구조도 등)으로 표현하십시오.

- 1.4 메인 페이지 IA(정보구조) 및 와이어프레임 설명(섹션별 노출 로직: 인기순/신상품/개인화 추천 등)
